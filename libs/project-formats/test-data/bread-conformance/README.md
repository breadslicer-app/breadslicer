# .bread conformance files

Copied from [bread-format](https://github.com/breadslicer-app/bread-format) `v0.2.0`,
`conformance/` (Apache-2.0). Breadslicer opens every file in `valid/` and refuses every file in
`invalid/`. Their JSON descriptions stay in that repository, which checks the crate against them.

Copy them again when Breadslicer moves to a newer tag of the crate.
